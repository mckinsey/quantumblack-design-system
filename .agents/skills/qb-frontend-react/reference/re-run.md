# Re-run

Open **only** when the user changes requirements or a design decision mid-flight (or mid-build).

| Change | Action |
| --- | --- |
| Requirements | Update stage 1 → set later sections to `pending` or revise → re-confirm from stage 1 → then 2 → 3 → build |
| UX design | Update stage 2 (JSON `stories`) → revise stage 3 → re-confirm 2 then 3 → build |
| UI structure only | Update stage 3 → re-confirm 3 → build |

Say what invalidated. Do not keep coding on a stale plan. Pause → re-run → confirm → continue or rewrite.
