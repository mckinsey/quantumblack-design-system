# QB Design Library

Vite + React Router + shadcn/ui component registry for the QB Design System.

## Stack

- Vite, React 19, React Router v7, TypeScript, Tailwind CSS v4
- TanStack Query for data fetching on component detail pages
- Components built on Radix UI, styled to the QBDS design spec
- Registry generated via `npx shadcn build` → `public/r/`

## Key commands

```bash
npm run dev             # rebuild registry + dev server (port 4123)
npm run build           # rebuild registry + Vite production build → dist/
npm run preview         # preview production build (port 4123)
npm run registry:build  # rebuild registry only
npm run lint            # ESLint
```

## Adding a new component

1. Add the component to `src/components/ui/`
2. Add a demo in `src/app/demo/[name]/index.tsx` and `src/app/demo/[name]/ui/`
3. Register it in `registry.json` (follow the `alert` / `alert-demo` pattern)
4. Run `npm run registry:build` to regenerate registry files
5. Add a Figma Code Connect mapping (see below)

## Figma Code Connect

Code Connect maps each `src/components/ui/*.tsx` component to its Figma
counterpart in the QBDS library
(`https://www.figma.com/design/iuMWqCsIohoKAUB0tBS0xr`) so Dev Mode shows the
project's real snippet instead of an autogenerated one.

Configuration lives in `figma.config.json`. Set `FIGMA_ACCESS_TOKEN` in `.env`
(token with the `code_connect:write` scope) before running any of the commands
below.

```bash
npm run code-connect:create -- <figma-node-url>  # scaffold a new <name>.figma.tsx next to its component
npm run code-connect:parse                       # validate locally without uploading
npm run code-connect:publish                     # publish all mappings to Figma
npm run code-connect:unpublish                   # remove published mappings
```

Mapping files live next to their component as `<name>.figma.tsx` (e.g.
`src/components/ui/avatar.figma.tsx`). They are excluded from the build and
from the published shadcn registry; only the React source ships to consumers.

## Before raising a PR

- [ ] `npm run build` passes
- [ ] `npm run lint` passes
- [ ] `registry.json` updated and `npm run registry:build` run (if component added/changed)
- [ ] If the component changed shape, `npm run code-connect:parse` passes and the matching `*.figma.tsx` is updated
