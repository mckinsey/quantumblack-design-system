### PR-C — Material Symbols icon library (large, but mostly mechanical)

The bulk of the work. 3,900 generated `.tsx` icon components + 26 CC files mapping them to the published Figma icon library (4,149 connections total). This is a big PR by line count but trivial by review surface — the icons are autogenerated and the CC files follow a simple repeating pattern.

**Files to add:**

```text
src/icons/index.ts                     # barrel export

```

**Suggestion**: split into two commits within the PR — first commit adds the 3,900 icon components + barrel; second commit adds the 26 CC mapping files. Reviewers can skip the first commit's diff entirely and focus on whether the CC pattern in `code-connect-a.figma.tsx` is correct (the other 25 follow the same pattern).

**Optional alternative**: if 3,900 files is too many to commit in one go, the icon components could be moved to a separate `@qbds/icons` package and pulled in as an external dependency (the existing `figma.config.json` already maps `src/icons/*` → `@qbds/icons` for the published code snippet). That is a larger architectural call; keep the in-repo approach unless someone has explicit appetite to extract.

**Validation:**

```bash
npx figma connect publish --dry-run --skip-update-check --exit-on-unreadable-files
# expect: 4,153 mappings parsed cleanly
```

### PR-D — CI: automate `figma connect publish` on merge to main

So the CC mappings are regenerated in Figma whenever this repo's source changes.

**File to add:** `.github/workflows/code-connect-publish.yml`

```yaml
name: Publish Code Connect mappings

on:
  push:
    branches: [main]
    paths:
      - 'src/components/ui/**/*.figma.tsx'
      - 'src/icons/**/*.figma.tsx'
      - 'src/icons/**/*.tsx'
      - 'src/components/ui/icon-shell.tsx'
      - 'src/components/ui/badge.tsx'
      - 'figma.config.json'
  workflow_dispatch:

jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '24'
          cache: 'npm'
      - run: npm ci
      - name: Publish to Figma
        env:
          FIGMA_ACCESS_TOKEN: ${{ secrets.FIGMA_ACCESS_TOKEN }}
        run: npx figma connect publish --skip-update-check --exit-on-unreadable-files --batch-size 500
```

Add the `FIGMA_ACCESS_TOKEN` repository secret in GitHub Settings → Secrets and variables → Actions before merging this PR.
